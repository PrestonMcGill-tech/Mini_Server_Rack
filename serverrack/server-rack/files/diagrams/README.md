# Diagrams

Drop wiring diagrams, rack elevation/layout diagrams, network topology diagrams, etc.
here. Hand-drawn-and-scanned is completely fine — the goal is that someone else could
understand the power and data layout without you standing next to them.

```
rack-elevation.png     # front-view diagram showing what's mounted in each U
power-wiring.png       # PDU -> devices, UPS if any
network-topology.png   # if useful alongside your homelab docs
```
