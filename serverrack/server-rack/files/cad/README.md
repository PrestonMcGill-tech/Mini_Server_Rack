# CAD

Drop CAD files here — SolidWorks/Inventor native files, plus exported STEP/DXF/PDF
versions so people without the native software can still view them.

```
server-rack.sldprt / .sldasm     # native files
server-rack.step                 # neutral exchange format (viewable anywhere)
server-rack-drawing.pdf          # dimensioned drawing, if you made one
```

If you didn't CAD this before building it, that's fine — note that in the build log
instead ("designed by sketch/measurement, no CAD model").
