# Photos

Drop build and finished photos here. Suggested naming so they sort sensibly and are
easy to reference from the docs:

```
hero.jpg              # best finished-build shot — used at the top of the main README
01-planning.jpg
02-materials.jpg
03-fabrication-a.jpg
03-fabrication-b.jpg
04-finishing.jpg
05-fitout.jpg
06-finished-a.jpg
06-finished-b.jpg
```

A few before/during/after shots go a long way — reviewers looking at a portfolio repo
almost always look at the photos before reading the text. Delete this file once you've
added real photos, or leave it as a reference.

Tip: keep individual images under a few MB (resize/compress) so the repo stays fast to
clone — GitHub isn't a great home for full-resolution camera originals.
